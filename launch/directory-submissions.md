## SECTION "REVIEWS G2 / CAPTERRA" — Stratégie P1

### Pourquoi les reviews sont critiques

Un listing G2/Capterra sans review est invisible dans les algorithmes de ces plateformes. Le threshold minimum pour apparaître dans les catégories comparatives est de 5 reviews. Les reviews organiques arrivent rarement seules en early stage — il faut orchestrer une campagne de collecte.

### Timing de collecte

**NE PAS demander de reviews avant J+14** (attendre que les premiers utilisateurs aient eu le temps d'utiliser le produit réellement). Reviews sollicitées trop tôt = reviews génériques sans substance = peu utiles.

**Fenêtre cible :** J+14 → J+30 (utilisateurs trial-to-paid sur le Starter 39€).

### Templates email "invite à reviewer" (à envoyer par Resend depuis sequences)

**Email sujet :** "2 minutes pour aider Konvert à grandir ?"

```
Bonjour [PRÉNOM],

Permuter entre la description 160 chars, 260 chars et 800 chars selon les limites. Varier l'ordre des phrases dans la 800.

Mixer systématiquement ces anchors dans les descriptions et les profils :

Ne jamais utiliser le même anchor dans deux soumissions consécutives.

Aucun lien payant via des réseaux PBN ou des "DA 40+ dofollow backlink packages". Ces pratiques violent les guidelines Google Webmaster et peuvent déclencher une penalty manuelle.
